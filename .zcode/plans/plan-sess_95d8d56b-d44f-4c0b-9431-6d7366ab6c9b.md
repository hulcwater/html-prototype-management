## 目标
访问 `http://localhost:8787`（管理后台）需要输入密码；预览链接 `http://localhost:8787/preview/<id>/` 无需密码即可打开；登录后记住状态，下次打开不用再输入。

## 方案概览
无状态会话方案，不改数据库 schema：
- **密码**：SHA-256 哈希存储。本地首次运行自动生成随机密码并打印到控制台，同时保存到 gitignored 的 `.env.auth` 文件；也支持 `AUTH_PASSWORD_HASH` / `AUTH_PASSWORD` 环境变量。
- **登录态**：HttpOnly Cookie（`proto_session`），HMAC-SHA256 签名的随机令牌（secret 由密码哈希派生）。登录页勾选「记住我」（默认勾选）→ Cookie 有效期 30 天；不勾选 → 仅浏览器会话内有效（关浏览器需重新登录）。点击侧边栏「退出登录」清除 Cookie。

## 公开路径（无需密码）
- `/preview/*`（用户明确要求免登录）
- `/api/auth/*`（登录/登出接口本身）、`/health`
- `/login.html`（登录页）、`/static/*`、`/favicon.ico`（登录页所需静态资源）

## 新增文件
1. **`src/auth.ts`** — 纯鉴权工具 + Hono 中间件：
   - `sha256()`、timing-safe 比较、`verifyPassword(password, hash)`
   - `createSessionToken(hash, remember)` / `verifySessionToken(cookie, hash)`
   - `authGate` 中间件：公开路径直接放行；未登录访问 API → 401 JSON；未登录访问页面 → 302 跳转 `/login.html`
   - 不含任何 Node 特有 I/O，可同时运行在 Node（本地）和 Cloudflare Workers
2. **`src/routes/auth.ts`** — `POST /api/auth/login`（校验密码，成功则 `Set-Cookie`，remember 决定 30 天/会话级）、`POST /api/auth/logout`（清除 Cookie）
3. **`public/login.html`** — 独立登录页（内联样式，不依赖 app.js）：密码输入框、记住我勾选、错误提示、回车提交，成功后跳转 `/`

## 修改文件
4. **`src/types.ts`** — Bindings 增加 `AUTH_PASSWORD_HASH: string`
5. **`src/index.ts`** — 注册 `authGate` 中间件 + `/api/auth` 路由（放在其余 API 路由之前）
6. **`dev-server.ts`**（本地入口）：
   - 启动时加载/生成密码哈希并注入 bindings（env → `.env.auth` → 自动生成+写入+控制台打印）
   - 静态文件服务加鉴权：`/static/*`、`/login.html`、`/favicon.ico` 公开，其余路径未登录 302 → `/login.html`（`/preview/`、`/api/`、`/health` 本就转发给 Hono）
7. **`public/static/app.js`** — API 收到 401 时跳转 `/login.html`；新增 `logout()`（调 `/api/auth/logout` 后跳登录页）
8. **`public/index.html`** — 侧边栏底部增加「退出登录」按钮
9. **`public/static/style.css`** — 退出登录按钮样式
10. **`.gitignore`** — 加入 `.env.auth`
11. **`public/_routes.json`** — Cloudflare 侧改为 `include: ["/*"]`、`exclude: ["/static/*", "/favicon.ico"]`，让根路径 `/` 也经过 Hono 网关鉴权（移除 `/index.html` 的 exclude）
12. **`README.md` / `DEPLOY.md`** — 密码配置说明：本地自动生成/重置方法；线上用 `wrangler secret put AUTH_PASSWORD_HASH` 注入哈希（未设置 secret 时线上保持原样不启用鉴权，避免破坏现有部署）

## Cookie 细节
`proto_session`，HttpOnly、SameSite=Lax、Path=/；本地 HTTP 不设 Secure，生产 HTTPS 设 Secure。

## 验证
- `npm run type-check` 通过
- 启动 `npm run dev`：访问 `/` 应跳转 `/login.html`；输入控制台打印的密码可登录并跳转 `/`；勾选记住我后重启浏览器免登录；`/preview/<id>` 无需密码直接打开；退出登录后回到登录页
